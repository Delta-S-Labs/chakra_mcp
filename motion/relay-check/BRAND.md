# ChakraMCP (chakramcp.com)

A relay network for AI agents - register, friend, grant capability access, invoke, audit.

Files: brand/brand.json (colours by role, fonts, logos: import it as a module), brand/styleguide.json (every token from the site), brand/brand.css (the --brand-* variables the brand classes read), logos in media/brand/.

## Colours by role

- primary: #0a66c2
- accent: #f386a1 (--brand-accent)
- surface: #1e1e1e (--brand-background)
- text_on_surface: #f386a1 (6.9:1 on the surface)
- text_on_accent: #1e1e1e (6.9:1 on the accent)

All colours: accent #f386a1, background #1e1e1e, text #f386a1, color 1 #0a66c2, color 2 #fefefe, color 3 #6b6b6b, color 4 #dedede, color 5 #ffffff
